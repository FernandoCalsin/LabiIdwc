Estándares y formatos del entorno Web

Introducción a PNG, SVG, OGG y XML y su importancia dentro del desarrollo y funcionamiento de la Web.

Introducción Formatos Comparación Conclusión

Introducción

El entorno Web está compuesto por diferentes tecnologías, formatos y estándares que permiten crear, transmitir y presentar información a través de Internet. Entre ellos encontramos formatos destinados a imágenes, gráficos, audio y almacenamiento estructurado de información.

En este apartado se presentan cuatro tecnologías relevantes: PNG, SVG, OGG y XML. Cada una posee características y objetivos diferentes, pero todas pueden encontrarse relacionadas con el desarrollo de aplicaciones y contenidos para la Web.

Formatos y tecnologías

1. PNG

PNG (Portable Network Graphics) es un formato de imagen digital diseñado para almacenar imágenes mediante compresión sin pérdida de información.

Características

  • Utiliza compresión sin pérdida.
  • Permite utilizar transparencia.
  • Conserva buena calidad de imagen.
  • Es ampliamente utilizado en la Web.

Uso en HTML

<img
    src="imagen.png"
    alt="Imagen de ejemplo"
    width="300">

La etiqueta <img> permite insertar una imagen PNG dentro de una página web.

2. SVG

SVG (Scalable Vector Graphics) es un formato basado en XML utilizado para representar gráficos vectoriales.

Características

  • Puede ampliarse sin perder calidad.
  • Está basado en XML.
  • Puede escribirse directamente en HTML.
  • Es útil para iconos, diagramas y gráficos.

Ejemplo visual

Uso en HTML

<svg width="200" height="120">

    <circle
        cx="100"
        cy="60"
        r="45">

    </circle>

</svg>

3. OGG

OGG es un formato contenedor multimedia abierto desarrollado originalmente por la organización Xiph.Org. Puede utilizarse para almacenar y transmitir contenido multimedia, especialmente audio.

Características

  • Es un formato abierto.
  • Puede utilizarse para contenido multimedia.
  • Es compatible con HTML5 mediante elementos multimedia.
  • Puede contener audio codificado con diferentes códecs.

Uso en HTML

<audio controls>

    <source
        src="audio.ogg"
        type="audio/ogg">

    Tu navegador no admite
    este formato.

</audio>

El atributo controls permite mostrar los controles para reproducir el contenido de audio.

4. XML

XML (Extensible Markup Language) es un lenguaje de marcado diseñado para almacenar, organizar y transportar información estructurada.

Características

  • Permite estructurar información.
  • Utiliza etiquetas definidas por el usuario.
  • Es legible tanto para personas como para programas.
  • SVG utiliza XML como base.

Ejemplo XML

<alumno>

    <nombre>Juan</nombre>

    <curso>
        Desarrollo Web
    </curso>

    <semestre>III</semestre>

</alumno>

En este ejemplo, XML permite organizar los datos de un estudiante mediante una estructura jerárquica.

Comparación de los formatos

Formato Significado Principal utilización Tipo de contenido
PNG Portable Network Graphics Imágenes Gráfico rasterizado
SVG Scalable Vector Graphics Gráficos e ilustraciones Gráfico vectorial
OGG Formato multimedia abierto Audio y multimedia Multimedia
XML Extensible Markup Language Datos estructurados Texto estructurado

Conclusión

El conocimiento de diferentes estándares y formatos permite comprender mejor el funcionamiento del entorno Web. PNG proporciona una alternativa adecuada para el almacenamiento de imágenes con buena calidad y transparencia; SVG permite crear gráficos vectoriales escalables; OGG proporciona una alternativa abierta para contenido multimedia; y XML permite representar información de manera estructurada.


Aunque cada tecnología tiene un propósito diferente, todas pueden contribuir al desarrollo de contenidos y aplicaciones Web. Comprender sus características y formas de utilización permite a los estudiantes de Ingeniería de Sistemas desarrollar páginas más estructuradas y comprender mejor la relación entre los diferentes componentes que forman parte del entorno Web.
